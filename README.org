* LifeGPU
Game of Life simulation on WebGPU
(although we are currently simulating [[https://conwaylife.com/wiki/StarWars][StarWars]],
because it looks more interesting :3)

Check if you can use WebGPU in your browser: https://caniuse.com/webgpu.

E.g. in Firefox, go to =about:config= and set =dom.webgpu.enabled= to =true=.

Then, visit https://42loco42.github.io/life-webgpu!
